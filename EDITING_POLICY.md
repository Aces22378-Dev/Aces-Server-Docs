# EDITING POLICY

**Author:** Aces22378-Dev

## 1. PURPOSE

This repository is publicly readable, but it is **not open for public editing**.

The documentation is maintained by authorized members of the server's documentation or leadership team.

## 2. PUBLIC ACCESS

Anyone may:

* Read the documentation.
* View the documentation.
* Reference the documentation.
* Share links to the documentation.

## 3. EDITING RESTRICTIONS

Only authorized maintainers may modify the official documentation.

Members of the public should not:

* Edit official documents.
* Submit unauthorized changes.
* Replace official documentation.
* Remove documentation.
* Add unofficial policies.
* Modify staff responsibilities.
* Modify server rules.
* Add misleading information.

## 4. SUGGESTIONS

Suggestions for corrections or improvements may be communicated to the appropriate server staff.

A suggestion does **not** automatically become an official change.

Only authorized maintainers may approve and publish changes.

## 5. OFFICIAL DOCUMENTATION

A document should only be considered official when it has been published or approved by the authorized server leadership/documentation team.

Unofficial copies, forks, screenshots, or modified versions should not be treated as official server policy.

## 6. SECURITY

Do not attempt to bypass repository permissions or access controls to modify documentation.

Security concerns should be reported according to `SECURITY.md`.

## 7. FINAL NOTE

The documentation is public for **transparency and reference**, not public editing.

**Visibility:** Public
**Reading:** Allowed
**Editing:** Authorized maintainers only
